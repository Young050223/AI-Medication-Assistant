# Tech Stack

## Framework & Runtime

- Framework: Vite + React 19
- Language: TypeScript
- Runtime: Browser + Capacitor iOS + Supabase Edge Functions

## Core Dependencies

- Native shell: Capacitor iOS
- Backend: Supabase client + Edge Functions
- Icons: Custom React icon components in `src/components/Icons.tsx`
- State: React Context / localStorage
- CSS: Vanilla CSS modules/files

## Build & Deploy

- Build: `npm run build`
- Dev: `npm run dev`
- iOS sync: `npm run ios:rebuild`
- Deploy: Static web assets + Capacitor iOS package
